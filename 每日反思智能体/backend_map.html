🖥️ 后端（Backend）
💡 后端是什么 概念
用户看不见的部分
前端是餐厅大厅，后端是厨房。菜在厨房做好，再端出来给客人。
三件事：接请求 → 处理逻辑 → 存/取数据
用户点「保存」→ 后端收到 → 验证数据 → 写入数据库 → 返回结果
你的项目用 Python + Flask
Flask 是一个 Python 框架，帮你快速搭建后端，不用从零写。
📡 HTTP 通信 前后端对话方式
GET — 获取数据
「给我今天的活动列表」
GET /api/activities?date=2026-03-31
POST — 新建数据
「帮我保存这条新活动」
POST /api/activities
PUT — 修改数据
「帮我修改第3条活动」
PUT /api/activities/3
DELETE — 删除数据
「删掉第3条活动」
DELETE /api/activities/3
🗺️ 路由 地址 → 函数
路由 = 地址到函数的对应表
用户访问某个地址，后端知道该执行哪个函数。
页面路由 → 返回 HTML
浏览器访问，返回完整的页面。
@app.route('/') → 返回 index.html
API 路由 → 返回 JSON
JS 用 fetch 调用，返回数据，不返回页面。
@app.route('/api/...') → 返回 {}
🗄️ 数据库 存数据的地方
表 = Excel 表格
每列是字段（日期/时间/内容），每行是一条记录。
SQL — 操作数据库的语言
4 个核心操作：
SELECT（查）INSERT（增）UPDATE（改）DELETE（删）
你的项目用 SQLite
最简单的数据库，所有数据存在一个文件里：data/reflection.db
🚦 状态码 后端的回复信号
✅ 200 — 成功
请求成功，数据在这里。
✅ 201 — 创建成功
新数据已经存好了。
❌ 400 — 请求有问题
你发来的数据有错，比如漏了必填字段。
❌ 404 — 找不到
你要的那条数据不存在。
❌ 500 — 后端出错
服务器内部出了问题。
🤖 AI 服务 调用 Claude API
后端调用外部 API
后端也可以去请求别人的接口，就像前端请求你的后端一样。
流程
把活动数据格式化成文字 → 发给 Claude → 拿回反思内容 → 存数据库 → 返回给前端
需要 API Key
访问 Claude 的「门票」，存在环境变量里，不能写死在代码里。
