# 习惯养成知识库

## 习惯的本质
- 习惯是大脑的自动化程序：减少决策消耗，释放认知资源
- 习惯不是靠「意志力」，而是靠**系统设计**
- 改变行为最有效的方式：改变环境，而不是改变自己

## 习惯回路（Habit Loop）

**三要素**：触发 → 行为 → 奖励

- **触发（Cue）**：时间/地点/情绪/人/前置行为
- **行为（Routine）**：习惯本身
- **奖励（Reward）**：大脑获得的满足感

**改变习惯的关键**：保持触发和奖励不变，替换中间的行为。

## 建立新习惯的方法

### 原子习惯（James Clear）四定律
1. **让它显而易见**：把触发信号放在显眼位置（把健身鞋放在床边）
2. **让它有吸引力**：将习惯与喜欢的事物捆绑（只在跑步时听喜欢的播客）
3. **让它易于执行**：降低阻力（准备好工具，减少步骤）
4. **让它令人满足**：建立即时奖励（完成后打勾，视觉化进度）

### 习惯叠加（Habit Stacking）
格式：「**完成[现有习惯]之后，我将[新习惯]**」
- 「早上刷完牙之后，我将冥想5分钟」
- 「午饭后坐下来之前，我将散步10分钟」

利用已有习惯作为锚点，不需要额外记忆触发时机。

### 两分钟规则
任何新习惯，从「两分钟版本」开始：
- 想养成阅读习惯 → 先做到「每天打开书翻一页」
- 想养成运动习惯 → 先做到「穿上运动鞋站到门口」

**原理**：开始是最难的部分，降低启动阻力才能建立一致性。

### 实施意图（Implementation Intention）
格式：「**在[时间][地点]，我将[行为]**」
- 「每天早上7点，在厨房，我将喝一杯水」
- 研究表明，比只有「我要做X」的意图，成功率提高2-3倍

## 维持习惯的策略

### 不破链法则（Don't Break the Chain）
- 在日历上连续打勾，视觉化连续记录
- 核心规则：「绝不连续错过两次」
- 一次失误是意外，两次失误是新习惯（坏习惯）的开始

### 最小可行习惯
- 设定「最小剂量」：即使状态再差也能完成的版本
- 例：「即使很累，也要做5个俯卧撑」
- 保证一致性比完美执行更重要

### 身份认同
- 最持久的改变从「身份」开始，而不是「结果」
- 「我想减肥」（结果导向） vs 「我是一个注重健康的人」（身份导向）
- 每次坚持习惯，都是在投票给你想成为的那个人

## 戒掉坏习惯

### 反向四定律
1. **让触发不可见**：把手机放在另一个房间，删除 App
2. **让它没有吸引力**：重新认识坏习惯的代价（写下它带来的负面影响）
3. **让它难以执行**：增加阻力（在垃圾食品和你之间加一道障碍）
4. **让它令人不满**：建立即时惩罚机制（告诉朋友，打破时要做某件事）

## 常见失败原因与对策

| 失败原因 | 对策 |
|---------|------|
| 目标太大 | 缩小到原来的1/10 |
| 依赖动力 | 建立环境触发，不靠感觉 |
| 追求完美 | 「完成」比「完美」更重要 |
| 没有追踪 | 每日打勾，可视化进度 |
| 孤军奋战 | 找一个习惯伙伴或公开承诺 |

## 习惯养成时间线
- 心理学研究：平均66天（不是21天）形成自动化习惯
- 简单习惯（喝水）：18天
- 复杂习惯（运动）：66-254天
- 重要：一致性 > 天数，断掉后重启不要从头计数
