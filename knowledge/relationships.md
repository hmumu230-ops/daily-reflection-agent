# 人际关系知识库

## 关系的基础
- 所有关系的核心：安全感（我能真实做自己吗？）+ 被看见（我的感受被理解吗？）
- 关系质量 = 沟通质量 + 边界清晰度 + 修复能力
- 关系不是找到「对的人」，而是持续「做对的事」。

## 沟通框架

### 非暴力沟通（NVC）四要素
1. **观察**（不评判）：「这周你有3次没有回我消息」而不是「你总是忽略我」
2. **感受**：「我感到失落和担心」
3. **需求**：「我需要感受到我们之间的连接」
4. **请求**（具体可行）：「你能在24小时内回复我吗？」

### 主动倾听技巧
- **反映感受**：「听起来你当时很委屈」
- **澄清而非假设**：「你说的'压力很大'，是指哪方面？」
- **避免立即建议**：先确认对方想要倾听还是建议
- **身体语言**：放下手机，保持眼神接触，身体略微前倾

### 困难对话的准备
- 选择时机：双方都平静、不疲惫的时候
- 以「我」开头：「我感到…」而不是「你让我…」
- 一次只谈一个问题，不翻旧账
- 目标是理解，不是赢得争论

## 关系中的常见困境

### 冲突处理
**冲突风格识别**：
- 回避型：不说出来，积累到爆发
- 攻击型：情绪化指责，对方防御
- 被动攻击型：表面同意，暗中抵抗
- 健康型：直接表达，寻求共同解决

**冲突修复步骤**：
1. 冷静期（24-48小时）
2. 各自梳理：「我的感受是什么？我的需求是什么？我的责任是什么？」
3. 重新对话：先倾听对方，再表达自己
4. 共同找解决方案，而不是谁对谁错

### 边界设定
- 边界不是墙，是让关系持续的空间
- 设定边界三步：1）清楚说出界限 2）说明后果 3）一致执行
- 对「不」感到内疚是正常的，但不是不设边界的理由
- 无法设边界通常来自：担心被抛弃、不值得被尊重的信念

### 关系中的期望管理
- 说出期望，而不是假设对方应该知道
- 区分「需求」（必须满足）和「偏好」（最好有）
- 接受他人有不同的需求层级

### 远离有害关系的信号
- 持续感到被贬低、控制或不被尊重
- 在这段关系中不能做真实的自己
- 付出与回报长期严重失衡
- 感到恐惧而不是安全感

## 关系的修复与深化
- **道歉的要素**：承认具体行为 + 表达理解对方的感受 + 说明你会如何改变
- **感激练习**：每周对重要的人表达一次具体的感谢
- **共同经历**：关系在共同活动中加深，而不只是交流中
- **好奇心**：保持对对方生活的真诚兴趣
